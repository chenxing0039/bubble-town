# 泡泡小镇 · 摇杆试玩版 v0.4

非官方水泡对战玩法原型。1 人对战 3 个电脑。

## 打开

iPad 在 Safari 中打开本仓库的 GitHub Pages 网站。请使用游戏网址，不要在微信里预览 HTML 附件。

## 触屏操作

- 左侧空白区的大摇杆：按住并推向想移动的方向；松手停止。
- 右侧空白区的蓝色泡泡按钮：放水泡，可与摇杆同时使用。
- 水泡按钮下方的自救：被困时使用，每局一次。
- iPad 横屏时，操控区在游戏两侧；窄屏时自动放到地图下方，不覆盖地图。
- 电脑仍支持方向键 / WASD、空格、E、P、R。

摇杆有中心死区和方向稳定处理；遇到墙与木箱停止，不会穿越障碍。

## 声音

点击开始后启动。音效、音乐可单独关闭；没有声音请点“试听音效”并检查设备与网页音量。背景音乐使用 MP3 以便 Safari 解码。

## 素材与范围

画面为 AI 概念素材加工。声音与音乐为原创合成近似方案，未使用 B 站合集音轨，不是原版音频。

本项目不是官方游戏、原版客户端或原版素材包。已包含随机地图、炸箱、道具、连锁爆炸、自救、胜负判定；未包含联网与同机双人。无统计、无用户数据收集、全部素材内嵌。

## 避免网页手势干扰

游戏与操控区域设置 touch-action: none、禁止长按菜单/选中/拖拽，并对多指触摸及 Safari gesture 事件做游戏区域内拦截；不会全局禁止网页缩放，设置与说明区域仍可正常浏览。

iPad 可用 Safari 的分享菜单添加到主屏幕，再从图标打开，以独立窗口显示。浏览器或系统级边缘手势、系统辅助功能缩放无法由网页可靠禁止。没有添加离线缓存服务。
