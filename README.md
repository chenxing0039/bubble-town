# 泡泡小镇 · iPad 试玩版

非官方水泡对战玩法原型。1 人对战 3 个电脑。

## 打开游戏

通过本仓库的 GitHub Pages 网站打开。iPad 建议在 Safari 中访问网址，不要在微信内预览 HTML 附件。

点击“开始试玩”后启动音频；若无声，请点“试听音效”，确认设备及网页音量未静音。

## 操作

iPad：屏幕底部方向键、放水泡、自救按钮。
电脑：方向键或 WASD 移动；空格放水泡；E 自救（每局一次）；P 暂停；R 重开。

## 当前范围

- 随机村庄地图、木箱与石块
- 水泡连锁爆炸、道具升级、困人、自救与胜负判定
- 独立音效、背景音乐开关与总体音量
- 页面全部素材内嵌，不收集用户信息，不使用外部统计或依赖库

## 素材说明

画面使用 AI 概念图加工素材。音效和背景音乐为原创合成的近似方案，并非泡泡堂原版音频。没有加入 B 站合集音轨。

本项目为玩法练习，不是官方游戏、原版客户端或原版素材包。未包含联网与同机双人。
