# 泡泡小镇 v0.5

非官方玩法原型，单人对战 3 个电脑。

地图优先布局：横屏双侧低位操控区，240 px 摇杆；竖屏及小屏自动缩小并放在地图下方。左手摇杆移动，右手放水泡，自救每局一次。

左上“声音”可开关音效/音乐及调节音量，打开设置会暂停对局。开始试玩后启动声音。

音效 v0.5 为程序原创合成（水感短音设计），背景音乐仍为原创合成，未使用官方录音或网络音频。

素材检索记录：CrazyArcade/CrazyArcade 仓库 Resources/Sound 中有相关音频，但未确认官方来源及素材授权，因此未纳入本站。仓库代码许可证不等于官方音频授权。

iPad 建议在 Safari 打开，可添加到主屏幕。网页防误触不保证阻止系统边缘手势。无统计、无数据收集、无离线缓存。
